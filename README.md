# Chess Openings
## Project Overview
This website was built for fun. It's essentialy for studying Chess Openings, where you can input moves with different branches (different moves) and practice these openings to perfect them.
## Features
- Register/Sign In Account System
- Shared Openings
- Personal Openings
- Practice Openings
- Messaging System
- Manage Users
- Rank System (e.g Admin, Premium User)

## Disclaimer/Information
This project has been discontinued, there is already a fully built version of this available and I only built this as a fun project. It is functional, however the "build your own repitoire of openings" feature does not work, and you can only use pre-existing openings in the system, that I've added manually in the database.
